# Web 04 · Cinematic primitives 1: core components and the two signature reveals

## Goal

Build the first half of the Cinematic ("Programme") component catalogue for the web client in `frontend/src/skins/cinematic/primitives/`, together with the two reveals the owner requires (`SetHeading`: per-letter fade, slide up and un-blur, staggered; `TypedHeadline`: one character every 50 ms), the `play()` motion helper and `motion.css`, the grain, duotone and page-tint helpers with their contrast tests, spoken folios, and a development-only gallery page that the proof screenshots are taken from. Every component ships every state the contract lists (default, hover, pressed, focus-visible, disabled, loading, selected, error) and its reduced-motion variant. No screen changes in this step and legacy users see nothing new: the primitives are only reachable through the gallery until later steps compose screens from them. The skin is black stock, bone ink and one spot colour, radius 0 everywhere, rules instead of cards, no shadows, no glass, no springs in timed motion. If a skill or habit suggests rounded corners, gradients, drop shadows or frosted panels, the contract wins.
