## Goal

Build the Glass Library hub on the web client (`frontend/`): the Library shelf and Browse all (glass §8.17) with the pinch and Ctrl/⌘ + wheel density, the Density menu, the filters (progress chips, `reading_status`, tags) and the sections as in-page tabs on phones; Collections and collection detail (§8.18) with fanned stacks from `preview_covers`, Auto (smart) shelves and the shared-collection marker; History (§8.19); Bookmarks with the `?source&series` filter (§8.20); Updates (§8.21); and Downloads (§8.22) with the web's Chapters and Storage tabs, the running saves, the liquid storage meter, the Downloading accessory and the 18+ read-side filter. Swipe rows, drag to reorder, bulk selection, every state and every key are part of this step. When you finish, the ScreenIds `library`, `collections`, `collection`, `history`, `bookmarks`, `updates` and `downloads` leave the Glass `PENDING` set. Glass stays reachable only through the debug row (Settings → Diagnostics, CINEMATIC | GLASS); Cinematic must not change by a single pixel.
