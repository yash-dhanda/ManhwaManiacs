## Goal

Build the first Cinematic screens of the Flutter app and the 18+ gate end to end. Screens: Setup (mobile S01, cinematic §8.1: the server address with the URL keyboard, the IME `go` action, the HTTPS rule in release builds, and the signature move where the field's underline becomes the Oxford rule), the splash outcomes (S02, §8.2, on mobile/06's Press start), Login (S03, §8.3), Register (S04, §8.4), the profile picker "Who's reading tonight?" The gate: the certificate flow from the profile form (and, as a ready component, from Settings → Content, which mobile/18 mounts), the stamp, invalidation, the rating card, "absence, never a lock", and **local copies following the gate**: one skin-neutral filter, `mobile/lib/features/downloads/utils/mature_filter.dart`, over every device store that names a series (the sqflite download rows for manga, novels and saved narration audio, the offline bookmark store and its outbox, the offline follow cache, the progress outbox), each row stamped `mature` when stored and re-stamped when `mature_override` changes, with queued or running downloads of a hidden series pausing silently. When you finish, the ScreenIds `setup`, `login`, `register`, `profiles`, `profileNew`, `profileEdit` and `profilesManage` leave the Cinematic `PENDING` set.
