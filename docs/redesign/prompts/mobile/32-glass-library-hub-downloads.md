## Goal

Build the Glass Library hub in the Flutter app (`mobile/`, iOS and Android): the Library shelf and Browse all (glass §8.17) with pinch density, the Density menu and the Glass reading of the stored library-density values (§8.25.3 migration table, row "Library density"), the filters (progress chips, `reading_status`, tags) and the five sections as in-page tabs on phones; Collections and collection detail (§8.18) with fanned stacks, Auto (smart) shelves and the shared-collection marker; History (§8.19); Bookmarks with the `?source&series` filter and the offline outbox (§8.20); Updates (§8.21); and the phone Downloads of §8.22 with its three tabs **Chapters · Queue · Storage**, the liquid storage meter, the OCR run banner, pins, Save to Files, the queue with its pause reasons and drag-to-prioritise, the Storage switches and the cache cards. The Library dock tab's count badge and the bottom accessory's **Downloading** variant are wired to the same data. Swipe rows, drag to reorder, bulk selection, every state and every hardware-keyboard key are part of this step. When you finish, the ScreenIds `library`, `collections`, `collection`, `history`, `bookmarks`, `updates` and `downloads` leave the Glass `PENDING` map in `mobile/lib/skins/glass/router.dart`. Glass stays reachable only through Settings → Diagnostics → Edition (debug) (CINEMATIC | GLASS); Cinematic must not change by a single pixel.
