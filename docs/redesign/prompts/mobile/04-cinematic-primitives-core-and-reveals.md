# Mobile 04 · Cinematic primitives 1: core components and the two signature reveals

Track: mobile · Order 18 · Depends on: `docs/redesign/prompts/mobile/03-foundation-fonts-icons-harness-glass-gate.md` · Web twin: `docs/redesign/prompts/web/04-cinematic-primitives-core-and-reveals.md` · Proof folder: `docs/redesign/proof/mobile-04/`

## Goal

Build the first half of the Cinematic ("Programme") component catalogue for the Flutter app (iOS and Android) in `mobile/lib/skins/cinematic/primitives/`, on the generated `CineTokens`, together with the two reveals the owner requires (`SetHeading`: per-letter fade, slide up and un-blur, staggered, one `AnimationController` per heading and no package; `TypedHeadline`: one grapheme every 50 ms on a `Ticker`), the `CineMotion.play` helper with the skin-neutral motion recorder behind Settings → Diagnostics "Show motion timings", the grain fragment shader, the duotone and page-tint helpers with their contrast tests, spoken folios, the skin `ScrollBehavior`, the §3.3 text-scale rules, and a Diagnostics-only primitives gallery that the screenshot harness captures. Every primitive ships every state of its §7 table (default, pressed, focus on a hardware keyboard, disabled, loading, selected, error, and hover where a trackpad or mouse is attached) and its reduced-motion variant. No screen changes in this step and legacy users see nothing new except three debug rows in the legacy Diagnostics screen. The skin is black stock, bone ink and one spot colour, radius 0 everywhere, rules instead of cards, no shadows, no glass, no springs in timed motion. If a skill or habit suggests rounded corners, gradients on controls, drop shadows, ink ripples or frosted panels, the contract wins.

### B. Motion (`mobile/lib/skins/cinematic/motion.dart`, `motion_math.dart`, the skin-neutral recorder)

B1. **Reduced motion** (§4.8, §14.1): `CineMotionScope({required Widget child})` is a `ConsumerWidget` that watches `appReduceMotionProvider` and exposes an `InheritedWidget`; `static bool CineMotion.reduced(BuildContext context)` returns `MediaQuery.disableAnimationsOf(context) || scope.appReduced` (the scope absent means only the OS setting). Every primitive here reads `CineMotion.reduced(context)`, never `MediaQuery.disableAnimationsOf` alone. mobile/06 mounts the scope at the skin root; the gallery mounts it now.

B2. **`CineMotion.play`** (§4.5, §4.7): the single entry point for every named move. Signature: `static Future<void> play(MotionName name, AnimationController controller, {double target = 1.0, double? from, Duration? duration, Curve? curve})`. It sets `controller.duration` from the move's token when `duration` is null, starts the recorder entry (`MotionRecorder.instance.start(name.label, plannedMs)`), runs `controller.animateTo(target, curve: curve ?? token curve)` from the current value (from `from` when given), and ends the entry on completion or on interruption (`TickerCanceled` is caught and recorded as interrupted). Nothing queues: calling `play` again on the same controller retargets from its current value (§4.7). Look the `MotionName` members up by label in `motion_names.g.dart` (`SET`, `RULE DRAW`, `LETTER SET`, `TYPE`, `RACK FOCUS`, `DEVELOP`, `DRIFT`, `FLICKER`, `SLATE`, `RULE SLIDE`); never hand-type a label string.
   Moves implemented in this step (the others arrive with the step that first needs them: Folio flip, Insert, Rise, Arm, Lightbox and the menu clip in mobile/05; Page, Match cut, Dip, Column wipe and Iris in mobile/06; every remaining §4.5 name with the screen that first uses it):
   - **Set**: 320 ms (`durColumn`) per item, `CineCurves.settle`, opacity 0 → 1 and translate y 8 → 0 px.
   - **Rule draw**: 480 ms (`durSpread`), `settle`, `scaleX` 0 → 1 from the left end (`Transform` with `alignment: Alignment.centerLeft`).
   - **Letter set** (driven by `SetHeading`, item C1) and **Type** (driven by `TypedHeadline`, item C2): they report to the recorder through `CineMotion.track(MotionName name, int plannedMs)`, which returns the recorder handle for widgets that own their own controllers or tickers.
   - **Rack focus**: 520 ms (`durRack`), `settle`: `ImageFiltered` blur σ 14 (`blurRack`) → 0, brightness 0.6 → 1 through a `ColorFilter.matrix` scaling R, G, B by the brightness, scale 1.03 → 1; skipped when the image was loaded synchronously (`frameBuilder`'s `wasSynchronouslyLoaded`).
   - **Develop**: 520 ms, `settle`, opacity 0 → 1, brightness 0.6 → 1, scale 1.03 → 1, no blur.
   - **Drift**: 26 s (`durDrift`) alternate infinite (`controller.repeat(reverse: true)`), `CineCurves.drift`, scale 1.00 → 1.06 and translate −1 %, −1.5 % of the child's size.
   - **Flicker**: 1400 ms (`durFlicker`) half-period alternate, `CineCurves.drift`, opacity 0.55 ↔ 1, the phase offset +60 ms per item in reading order (start the controller at `value = (60 × index % 1400) / 1400`).
   - **Slate**: grow 320 ms `settle`, collapse 200 ms (`durClip`) `CineCurves.lift` after a 120 ms (`durSnap`) grace.
   - **Rule slide**: 320 ms `settle`, the underline moves and stretches to the new item.
