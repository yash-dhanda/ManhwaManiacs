# Recheck round 2: Glass web lens (`judge-web.md`, section "Confirmed")

Method: I checked all 21 confirmed findings again against the live `glass/DESIGN.md`, including the 17 that round 1 resolved, because other lenses' fix rounds kept editing the file while I worked (it grew from 4,586 to 4,603 lines). For each finding I read the edited sections in full and compared them with the judge's final fix. I then grepped for the old values the fix should have removed, and for every other place that repeats a changed value, to find contradictions. The round-2 changes listed in `fixed-web.md` (WEB-4, WEB-5, WEB-9, WEB-13, and O1 under WEB-1) were checked the same way. Section numbers are authoritative. Line numbers come from the 4,603-line state and may move.

Result: **19 resolved, 2 unresolved** (WEB-5, WEB-9). The four round-1 residuals are all fixed. The two findings still open each have a sentence elsewhere in the file that repeats a value the fix changed:

- **WEB-5:** the recap offer's desktop form.
- **WEB-9:** the `swell` haptic pattern, which is still sized for the old 1,200 ms fill.

Each needs a one-line edit.
