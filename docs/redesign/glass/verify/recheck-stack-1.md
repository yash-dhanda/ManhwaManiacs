# Recheck round 1: Glass stack lens (`judge-stack.md`, section "Confirmed")

Method: for each of the 28 confirmed findings I read every section the judge's final fix names in the live `glass/DESIGN.md` (reading the edited sections in full, not only the lines `fixed-stack.md` lists). I grepped for the old values the fix should have removed, and for every other place the changed value or rule is repeated, looking for contradictions. For the six duplicates (STACK-4, 9, 10, 15, 19, 20) I also confirmed that the other lens's base fix is in place, because the stack fix only adds to it. Primary sources were rechecked where a fix depends on a number: `cinematic/DESIGN.md` for the Circle, cover-name and worker protocol, and §4.2 for the sheet spring.

Other lenses' fix rounds were still editing `DESIGN.md` while I worked: it grew from 4,585 to 4,606 lines. I re-ran every anchor grep on the live file at the end. Section numbers are authoritative; line numbers are from the 4,606-line state and may drift.

Result: **24 resolved, 4 unresolved** (STACK-15, STACK-19, STACK-20, STACK-24). In all four the judge's fix itself is in place, exactly as written. What remains in each is one sentence elsewhere in the file that repeats the old rule and now contradicts the fix. Each needs a one-line edit.

## Observations (not blocking; outside the stack findings' final fixes or pre-existing)

- **O1 (STACK-6 wording).** §7.10 **The on-screen keyboard** (l. 1748) credits the focus-to-large rule to "the sheet route's own `Focus` listener, §15.3 Sheets", which is correct. It then adds "; `GlassModalSheet` 1.7.2 snaps to full on a focused descendant the same way". Since §15.3 says `GlassModalSheet` is not used, the aside only invites the reader to reach for it. Deleting it would lose nothing.
- **O2 (STACK-6 naming).** §15.3 **Sheets** *Keyboard* says the rule is "`GlassSheet`'s own". No class `GlassSheet` is declared anywhere; the file names `GlassSheetPage`, `GlassSheetRoute`, `GlassSheetPhysics` and `GlassSnapGrid`. Naming the widget that hosts the `Focus` listener (for example "the sheet body widget in `glass_sheet_route.dart`") would close this.
- **O3 (STACK-14 neighbour, pre-existing).** §9.4.2 **Rain on glass** gives web tier A "an animated SVG displacement map on the pill and capsules". §15.7 says "web displacement maps rebuilt only at rest", and STACK-14 adds "No map is built mid-motion" and "no `backdrop-filter` element is ever nested inside a bar group". The rain is the one web map that animates every frame over a bar group. The text should say how: an animated filter primitive on the group's own filter, or a sanctioned exception to "only at rest".
